# Kora – React Native (Expo)

1. `npx create-expo-app@latest kora --template blank`
2. Copy `App.js` and the `src/` folder from here into the new `kora/` project (overwrite App.js)
3. `cd kora && npx expo start`, then scan the QR code with Expo Go (or press `a` / `i` for an emulator)

No extra packages needed. Playback is simulated in App.js; swap in `expo-av` or `react-native-track-player` for real audio.
